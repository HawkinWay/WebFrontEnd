## 6. 什么是 AJAX? 优缺点是什么?

- 异步的 JavaScript 和 XML，能在不刷新整个网页的前提下，局部更新数据

- 优点：用户体验极佳（无需刷新、不卡顿）、减轻服务器压力

- 缺点：破坏了浏览器的前进后退功能、对 SEO（搜索引擎优化）不友好

## 7. 什么是 JSON? 优缺点是什么?

- 一种轻量级的文本数据交换格式（键值对形式，如 {"name": "Shovy"}）

- jQuery.parseJSON(): obj->JSON  ; JSON.parse(): JSON->obj

- 优点：结构简单、易于人阅读、主流语言 100% 原生支持

- 缺点：不能写注释、不支持复杂的特殊数据类型（如函数、正则）

## 8. JSON 与 XML 的区别

- JSON 没有冗余标签，体积更小，传输和解析速度更快

- XML 用前后标签包裹，更严谨；JSON 用键值对，更直观简练

- JSON 在 JS 中可以一行代码直接转对象，XML 解析起来极其繁琐

## 11. 事件冒泡和事件捕获的区别

- 事件冒泡: 事件从最外层的根节点（如 window 或 document）开始，沿着 DOM 树自上而下逐级传播，直到到达触发事件的目标元素

- 事件捕获: 事件从触发它的目标元素开始，沿着 DOM 树自下而上逐级向上传播，直到回到最外层的根节点

## 12. Bootstrap 的特点 优势及两个容器类

- 特点与优势: 响应式（一套代码适配手机、平板、电脑）、移动端优先、提供了大量开箱即用的精美组件

- 两个容器类:

    - .container: 固定宽度、两边留白的响应式容器
    - .container-fluid: 100%宽度、铺满全屏的流式容器

## 13. Bootstrap 中布局容器的概念

布局容器是 Bootstrap 框架的最外层根基（基座）。所有的行（.row）和网格列（.col-*）必须包裹在布局容器内，它负责控制页面的最大宽度、实现两边居中对齐，并奠定响应式断点测算的基础

## 14. Bootstrap 栅格系统的基本原理和响应式实现

- 基本原理：将页面一行死死分为 12 等份（列），通过给元素指定占几份（如 col-4 占 1/3）来控制宽度

- 响应式实现：通过内置的 屏幕媒体查询断点（sm, md, lg） 类名组合（如 col-12 col-md-6），实现手机上占满整行（12列），到了电脑上自动并排占半行（6列）

## 15. SessionStorage 和 LocalStorage 的区别与读写

- 区别（生命周期）：

    - sessionStorage：会话级存储，浏览器或标签页一关数据就没了
    - localStorage：永久级存储，除非手动卸载或清理，否则永远在硬盘里

- 读写操作：

    - 添加：localStorage.setItem("key", "value")
    - 移除：localStorage.removeItem("key")

## 16. 什么是 DOM 和 BOM？它们的区别？

- DOM: 文档对象模型, 把网页内容看作一棵树，根节点是 document，用来控制文字、标签

- BOM: 浏览器对象模型, 把浏览器本身看作对象，顶级是 window，用来控制弹窗、历史记录（history）、地址栏（location）

- DOM 是 W3C 标准，管网页里面的东西；BOM 是各大浏览器厂商自己定的，管网页外面的壳子。DOM 包含在 BOM 里面

## 17. HTTP 协议中 GET 和 POST 的主要区别

- 传参位置：GET 的参数挂在 URL 网址后面（肉眼可见）；POST 的参数放在 HTTP 请求体（Body）里面（肉眼不可见）

- 安全性：GET 极不安全（历史记录可见）；POST 相对安全

- 数据大小：GET 受网址长度限制（通常 2KB 左右）；POST 原则上无限制（可传大文件）

- 缓存与刷新：GET 会被浏览器主动缓存，刷新无害；POST 不会被缓存，刷新会提示重复提交

## 18. CSS选择器权重计算规则及 !important

- !important > 行内样式 > ID选择器 > 类/伪类选择器 > 标签选择器

- !important: CSS 里的“最高特权”，写在属性值后面可以直接打破一切权重规则，强行让该样式生效

## 19. 什么是 Canvas？它与 SVG 的主要区别？

- Canvas：HTML5 的位图（画布）。用 JS 脚本一行行画出来的像素点。放大会模糊（失真）。适合写高帧率游戏、粒子特效

- SVG: 基于 XML 的矢量图。用标签（如 rect ）定义的几何图形。放大永不模糊（不失真）。适合做图标（Icon）、高清地图、图表

## 20. CSS 三种引入方式的优先级关系

内联样式（标签内部 style="xxx"）> 内部样式表（head里的 style 标签）= 外部样式表（link 引入的 css 文件）
