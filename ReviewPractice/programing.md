# 编程题

1. 请使用媒体查询或者 Bootstrap 框架，实现使同一个页面在不同尺寸的设备浏览器 中呈现出与之适配的样式： 在大屏幕设备下(≥992px)，两栏布局 (3:1 比例)： 主内容区：col-lg-9 (占 9 列，即 75%) 侧边栏：col-lg-3 (占 3 列，即 25%)

2. 请使用 Bootstrap 框架或纯 CSS 媒体查询，实现一个响应式卡片布局页面： 桌面端（≥992px）：每行显示 4 张卡片，卡片间距 20px 平板端（≥768px 且<<992px）：每行显示 2 张卡片，卡片间距 15px 手机端（<<768px）：每行显示 1 张卡片，卡片间距 10px 每张卡片包含：图片区域（高度 200px）、标题、描述文字、按钮 要求卡片高度一致，图片自适应填充，文字溢出时显示省略号

3. 页面有一组复选框和一个"全选"按钮，点击按钮选中所有复选框，再次点击取消
全选。 

4. 使用 JavaScript 在页面中动态创建一个无序列表，列表项的内容为 1 到 10 的数 字。 

5. 使用 JavaScript 动态生成导航菜单数据（至少 5 项），并渲染到页面 

6. 有一个数据表格，使用 JavaScript 为奇数行添加背景色（浅灰色），为偶数行添加 白色背景，实现斑马纹效果。 

7. 创建一个用户注册表单页面，实现表单基础验证功能，验证以下字段： 用户名：3-20 个字符，只能包含字母、数字和下划线 密码：不为空 确认密码：必须与密码一致 年龄：18-100 之间的整数 电话：11 位，以 1 开头 

8. 用户在密码输入框输入密码，实时显示密码强度（弱/中/强）。 弱：纯数字或纯字母； 中：数字+字母； 强：数字+字母+特殊字符，且长度≥8。
